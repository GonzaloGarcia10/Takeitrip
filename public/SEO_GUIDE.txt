# Google Search Console Verification
# ================================
# Para verificar tu sitio en Google Search Console:
# 1. Ve a https://search.google.com/search-console
# 2. Añade tu propiedad (dominio o prefijo URL)
# 3. Selecciona "Método HTML tag" 
# 4. Copia el código de verificación que te dan
# 5. Actualiza el campo 'verification.google' en src/app/layout.tsx
